Sobre o Projeto

Esta página faz parte da atividade avaliativa AA2 da disciplina de Programação para Web, com o objetivo de praticar a criação de páginas estáticas em HTML e CSS. O tema escolhido pelo grupo foi uma loja fictícia de camisas de futebol, o Camisa10, que servirá de base para funcionalidades adicionadas em atividades futuras da disciplina.

Objetivos

Aplicar elementos semânticos de HTML5, organizar o conteúdo em cabeçalho, barra lateral, conteúdo principal e rodapé, além de construir um layout responsivo utilizando CSS puro (Flexbox e Grid), sem frameworks externos.

Sobre o Projeto

Camisa10 é um projeto acadêmico estático que simula uma loja de camisas de futebol, criado para a disciplina de Programação para Web da UFSC.

Objetivos

Praticar HTML semântico, vinculação de CSS externo e construção de layout responsivo para páginas web estáticas.
